Class dan object

Satu cetakan, banyak hasil cetak

Class ditulis sekali di kode. Object dibuat berkali-kali saat game berjalan, dan masing-masing menyimpan nilainya sendiri. Atur nilainya, lalu cetak beberapa object.

Class: cetakannya

public class WasteItem : GameEntity
{
    [SerializeField] protected int pointValue = 10;
    [SerializeField] protected float fallSpeed = 2f;

    protected virtual void Update()
    {
        // jatuh ke bawah, tiap frame
    }
}

Slider di bawah meniru Inspector Unity. Nilai dari Inspector mengalahkan nilai awal yang tertulis di kode.

Object: hasil cetaknya

Class: 1 Object hidup: 0 Pernah dibuat: 0 Sudah dihapus: 0
Belum ada object hidup. Tekan Buat object.

Class cuma satu. Object bisa banyak. Hapus satu object dan yang lain tetap jatuh, itulah arti berdiri sendiri. Garis ungu di tiap kartu adalah posisi jatuhnya. Kalau sudah penuh, object itu dihapus.

Constructor

Constructor jalan satu kali, tepat saat new

Tugasnya mengisi data awal object. Urutannya selalu parent class dulu, baru child class. Ini isi Latihan 1 di slide. Ubah isiannya lalu tekan Jalankan.
